# Инструкция для сокомандника

Этот файл нужен, чтобы быстро принять проект, установить APK, провести демо и понять, что можно показывать, а что лучше называть демо-функцией.

---

## 1. Что передать сокоманднику

Минимальный набор:

```text
1. StudyPulse-debug.apk
2. Ссылка на репозиторий:
   https://github.com/Diedsag/StudyPulse
3. Файлы:
   README.md
   INSTRUCTION.md
   FULL_DESCRIPTION.md
   docs/PROJECT_STATUS.md
   docs/PHASE4_RELEASE_NOTES.md
```

APK после сборки лежит здесь:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Скрипт финальной сборки также копирует его на рабочий стол:

```text
C:\Users\<user>\Desktop\StudyPulse-debug.apk
```

---

## 2. Установка APK

Самый простой способ:

```text
отправить StudyPulse-debug.apk в Telegram / WhatsApp / почту / на диск
```

Сокомандник:

1. Скачивает APK.
2. Открывает на телефоне.
3. Разрешает установку из неизвестных источников.
4. Устанавливает.

Если установка падает из-за уже установленной старой версии:

```text
сначала удалить старое StudyPulse, потом установить новый APK
```

Через adb:

```powershell
adb install -r "C:\Users\lelec\Desktop\StudyPulse-debug.apk"
```

При конфликте подписи:

```powershell
adb uninstall com.studypulse.sync
adb install "C:\Users\lelec\Desktop\StudyPulse-debug.apk"
```

## 3. Запуск без сервера

Продукт offline-first. Для базового демо сервер не нужен.

Работают:

```text
онбординг;
расписание;
импорт расписания;
задания;
материалы;
Q&A по добавленным материалам;
повторение карточек;
локальные напоминания;
резервные копии;
виджет.
```

Не будут работать без сервера:

```text
рейтинг;
XP с сервера;
streak с сервера;
учебные пакеты;
синхронизация событий.
```

## 4. Запуск с сервером для рейтинга

На ноутбуке:

```powershell
Set-Location -LiteralPath 'C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\backend'
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Убедиться, что Flask слушает:

```python
app.run(host="0.0.0.0", port=5000, debug=True)
```

Узнать IP ноутбука:

```powershell
ipconfig
```

Пример:

```text
192.168.1.69
```

В приложении:

```text
Настройки -> Для разработчиков -> Адрес сервера
http://192.168.1.69:5000
```

Если не подключается:

```text
1. Телефон и ноутбук в одной Wi-Fi сети.
2. Порт 5000 открыт в брандмауэре Windows.
3. Роутер не изолирует устройства.
4. Либо использовать adb reverse:
   adb reverse tcp:5000 tcp:5000
   и адрес:
   http://localhost:5000
```

## 5. Демо-скрипт на 3–5 минут

### 5.1 Первый запуск

Показать:

```text
установка;
онбординг;
ввод имени;
выбор времени учёбы;
включение уведомлений;
включение автоплана.
```

### 5.2 Задание

Создать задание:

```text
Название: Лаба по физике
Дедлайн: завтра или через 2 дня
Время: 60–120 минут
Приоритет: высокий
```

Показать, что приложение включает его в план.

### 5.3 Расписание

Показать:

```text
Добавить занятие;
все дни недели видны;
форму можно закрыть;
занятие сохраняется;
список отсортирован по дате и времени.
```

### 5.4 Импорт расписания

Вставить:

```text
Понедельник
10:00-11:30 Физика, лекция, ауд 204, Иванов А.П.
14:00-15:30 История, семинар, ауд 312
```

Нажать:

```text
Распознать
```

Прокрутить вниз и нажать:

```text
Импортировать выбранные
```

### 5.5 Материалы

Нажать:

```text
Материалы -> Добавить
```

Ввести:

```text
Название: Физика, лекция 1
Текст:
Температура — мера средней кинетической энергии частиц.
Измеряется в кельвинах и градусах Цельсия.
Нулевая температура соответствует минимальной энергии движения.
```

Показать:

```text
форму можно закрыть;
выбранный предмет виден;
сохранённый материал отображается с текстом.
```

### 5.6 Q&A

Открыть материал:

```text
Спросить по материалу
```

Задать вопросы:

```text
температура
что такое температура
кельвины
градусы Цельсия
нулевая температура
```

Ожидать ответ с цитатой.

Важно честно говорить:

```text
Это демо-поиск по материалам, не настоящий RAG.
```

### 5.7 Повторение

Открыть:

```text
Повторить карточки
```

Показать кнопки:

```text
Снова
Трудно
Хорошо
Легко
```

### 5.8 Статистика

Открыть вкладку:

```text
Статистика
```

Не нажимать «Обновить».

Показать, что автоматически обновляются:

```text
Неделя
Всё время
```

Если сервер не запущен, может быть ошибка сети. Это нормально для офлайн-демо.

### 5.9 Настройки и backup

Показать:

```text
Напоминания;
тихие часы;
Создать резервную копию;
список копий;
технические настройки в «Для разработчиков».
```

### 5.10 Виджет

Добавить виджет StudyPulse на рабочий экран.

Показать:

```text
дата;
ближайший слот;
срочные задания;
открытие приложения по клику.
```

## 6. Что говорить комиссии

### Почему Q&A не настоящий AI?

```text
Сейчас Q&A — честный демо-поиск по материалам. Мы не выдаём keyword search за RAG. Архитектура уже хранит материалы и чанки, поэтому следующий шаг — подключить векторный поиск и LLM без смены продуктовой модели.
```

### Почему OCR не распознаёт текст?

```text
Настоящий OCR — отдельная сложная задача: печатный текст, рукопись, качество фото, ML Kit или облачные API. Сейчас мы показали UX будущего сценария и подготовили место в продукте.
```

### Почему нет аккаунтов?

```text
Продукт offline-first. Локальный профиль и backup позволяют работать без регистрации. Аккаунты и мультидевайс — следующий этап, когда нужна облачная идентичность.
```

### Почему рейтинг не работает без сервера?

```text
Рейтинг — серверная геймификация. Локальные учебные функции работают офлайн, а сервер включает социальный слой: XP, streak, leaderboard.
```

### В чём отличие от обычного планировщика?

```text
Обычный планировщик хранит задачи. StudyPulse связывает расписание, задания, материалы, повторение, напоминания и прогресс в один учебный цикл.
```

## 7. Известные ограничения, которые не надо прятать

```text
Q&A — keyword search.
OCR — placeholder.
Push-уведомления — не серверные, только локальные Android notifications.
Нет аккаунтов.
Нет мультидевайс.
Нет релизной подписи.
Нет CI/CD.
Нет crash reporting.
```

Это нормально для демо Фазы 4. Главное — показать рабочий продуктовый цикл.

## 8. Если что-то не работает

Сначала проверить:

```text
1. Свежий ли APK установлен.
2. Не была ли старая версия с другой подписью.
3. Запущен ли backend, если нужен рейтинг.
4. Правильный ли адрес сервера.
5. Телефон и ноутбук в одной сети.
6. Открыт ли порт 5000.
```

Для логов Android:

```text
Android Studio -> Logcat -> filter: package:com.studypulse.sync
```

Для краша снять:

```text
FATAL EXCEPTION: main
...
Caused by: ...
```
