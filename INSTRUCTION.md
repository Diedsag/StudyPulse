# StudyPulse — Инструкция по использованию

## Возможности приложения

StudyPulse — это offline-first учебный ассистент для Android, который помогает студентам организовать учебный процесс, планировать занятия и отслеживать прогресс.

### Основные функции

Управление учебными пакетами:
- скачивание учебных пакетов с сервера;
- хранение расписания, заданий, материалов и карточек локально;
- офлайн-доступ после первой синхронизации;
- обновление пакетов при появлении новых данных.

Расписание и задания:
- просмотр расписания занятий;
- отмена отдельных занятий;
- список заданий с приоритетами, дедлайнами и трудоёмкостью;
- отслеживание статуса выполнения заданий.

Планировщик учебных слотов:
- автоматическое построение плана на основе расписания и заданий;
- учёт отменённых занятий;
- распределение времени по свободным окнам;
- предпросмотр плана;
- принятие плана.

Материалы и повторение:
- просмотр учебных материалов;
- ключевые факты и краткие саммари;
- интервальное повторение карточек по алгоритму SM-2;
- локальный mock Q&A по материалу без внешнего LLM.

Фокус-таймер:
- запуск таймера для учебного слота;
- пауза и сброс;
- отметка слота выполненным;
- автоматическое уменьшение остатка задания.

Статистика и прогресс:
- XP, уровень, недельный XP, streak;
- недельный рейтинг;
- рейтинг за всё время;
- локальный кэш статистики для офлайн-режима.

Синхронизация:
- локальная очередь событий;
- батчевая отправка на сервер;
- идемпотентность через client_event_id;
- повторная отправка не дублирует прогресс.

## Запуск на эмуляторе

### 1. Запуск backend

Открой PowerShell в корне проекта StudyPulse.

Первый раз нужно создать виртуальное окружение и установить зависимости:

    python -m venv backend/venv
    .\backend\venv\Scripts\python.exe -m pip install --upgrade pip
    .\backend\venv\Scripts\python.exe -m pip install -r backend/requirements.txt

Затем инициализируй базу данных:

    .\backend\venv\Scripts\python.exe backend/seed.py

Запусти сервер:

    .\backend\venv\Scripts\python.exe backend/run.py

Сервер будет доступен здесь:

    http://localhost:5000

Важно: не закрывай окно PowerShell с запущенным сервером, пока работает приложение.

### 2. Запуск Android-приложения

1. Открой Android Studio.
2. Открой проект из папки:

    android/

3. Дождись синхронизации Gradle.
4. Запусти эмулятор через Device Manager / AVD Manager.
5. Нажми Run.

### 3. Настройка подключения в эмуляторе

1. Открой вкладку Настройки.
2. В поле Адрес сервера введи:

    http://10.0.2.2:5000

3. Нажми Проверить.
4. Если подключение успешно, нажми Сохранить.
5. Нажми Синхронизировать.

Пояснение:

    10.0.2.2

— это специальный адрес хост-машины из Android emulator.

## Запуск на реальном устройстве

Схема: сервер Flask запущен на ноутбуке, Android-приложение установлено на телефоне. Оба устройства должны быть в одной сети.

### 1. Узнай IP-адрес ноутбука

Выполни в PowerShell:

    ipconfig

Найди IPv4-адрес активного адаптера, например:

    192.168.1.100

### 2. Запусти backend на ноутбуке

Если виртуальное окружение уже создано:

    .\backend\venv\Scripts\python.exe backend/seed.py
    .\backend\venv\Scripts\python.exe backend/run.py

Если окружение ещё не создано, сначала выполни блок из раздела про первый запуск backend.

### 3. Проверь сервер локально

На ноутбуке открой в браузере:

    http://localhost:5000/health

Должен вернуться JSON со статусом ok или healthy, в зависимости от текущей реализации health endpoint.

### 4. Разреши порт в firewall, если телефон не подключается

Если приложение на телефоне не видит сервер:

1. Открой Брандмауэр Windows Defender.
2. Перейди в Дополнительные параметры.
3. Создай правило для входящих подключений.
4. Тип правила: Порт.
5. Протокол: TCP.
6. Порт: 5000.
7. Действие: Разрешить подключение.

### 5. Установи приложение на телефон

Вариант A: через Android Studio

1. Подключи телефон по USB.
2. Включи режим разработчика:
   Настройки → О телефоне → Номер сборки, нажать 7 раз.
3. Включи отладку по USB:
   Настройки → Для разработчиков → Отладка по USB.
4. В Android Studio выбери устройство.
5. Нажми Run.

Вариант B: через APK

1. В Android Studio выполни:
   Build → Build Bundle(s) / APK(s) → Build APK(s).
2. Найди файл:

    android/app/build/outputs/apk/debug/app-debug.apk

3. Передачи APK на телефон.
4. Установи APK.

### 6. Настрой подключение в приложении

В приложении открой Настройки.

В поле Адрес сервера укажи:

    http://<IP-ноутбука>:5000

Например:

    http://192.168.1.100:5000

Затем:

1. Нажми Проверить.
2. Нажми Сохранить.
3. Нажми Синхронизировать.

## Основной сценарий использования

### Первый запуск

1. Открой приложение.
2. Перейди в Настройки.
3. Укажи адрес сервера.
4. Нажми Проверить.
5. Сохрани настройки.
6. Перейди в Пакеты.
7. Нажми Обновить.
8. Скачай хотя бы один учебный пакет.

### Ежедневный сценарий

1. Открой Расписание.
2. При необходимости отмени занятие.
3. Открой Задания.
4. Проверь дедлайны и приоритеты.
5. Открой План.
6. Нажми Сгенерировать план.
7. Проверь предложенные слоты.
8. Нажми Принять план.
9. Запусти Фокус-таймер для нужного слота.
10. После работы нажми Отметить выполненным.
11. Открой Материалы и повтори карточки.
12. Открой Статистика и нажми Обновить.
13. При наличии сети синхронизируй прогресс.

## Troubleshooting

### Сервер не запускается

Ошибка Address already in use означает, что порт 5000 уже занят.

Проверь:

    netstat -ano | findstr :5000

Затем заверши процесс через Диспетчер задач или используй другой порт.

Ошибка ModuleNotFoundError означает, что не активировано виртуальное окружение или не установлены зависимости.

Используй прямой запуск через venv Python:

    .\backend\venv\Scripts\python.exe backend/run.py

### Приложение не подключается к серверу

Для эмулятора используй только:

    http://10.0.2.2:5000

Для телефона используй IP ноутбука:

    http://192.168.1.x:5000

Проверь:

1. Сервер запущен.
2. Телефон и ноутбук в одной сети.
3. IP-адрес указан верно.
4. Порт 5000 открыт в firewall.
5. В адресе есть http:// и порт :5000.
6. В адресе нет лишнего /health на конце.

### Синхронизация не работает

Проверь:

1. Подключение через Настройки → Проверить.
2. Сервер запущен.
3. В очереди событий есть unsynced события.
4. Устройство зарегистрировано на сервере.
5. В логах Flask есть запрос POST /api/sync/batch.

### Приложение показывает старую версию

Очисти данные приложения на телефоне:

    Настройки → Приложения → StudyPulse → Хранилище → Очистить данные

Или переустанови APK.

## Технические детали

Backend:
- Python 3.11+;
- Flask;
- SQLAlchemy;
- SQLite;
- REST API;
- идемпотентная синхронизация событий.

Android:
- Kotlin;
- Jetpack Compose;
- Material 3;
- Room;
- DataStore;
- Retrofit;
- OkHttp;
- kotlinx.serialization;
- Coroutines / Flow.

Синхронизация:
- клиент создаёт события локально;
- события хранятся в Room с флагом synced;
- при синхронизации отправляются батчем;
- сервер принимает события по client_event_id;
- после успеха события помечаются как synced.
