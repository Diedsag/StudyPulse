# StudyPulse INSTRUCTION

Этот документ описывает, как собрать, установить, проверить и передать StudyPulse другому человеку.

## 1. Требования

Для разработки и сборки нужны:

- Windows / macOS / Linux;
- Android Studio;
- JDK 17;
- Android SDK;
- Git;
- Python 3.10+ для backend, если нужно запускать сервер.

## 2. Клонирование репозитория

Пример для Windows:

git clone <repo-url>
cd StudyPulse

Рабочая ветка Фазы 3:

git switch phase3-dev

Резервная ветка Фазы 2:

git switch phase2-freeze

## 3. Сборка Android APK

Открой папку android в Android Studio:

File -> Open -> C:\path\to\StudyPulse\android

Или собери через PowerShell:

cd C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\android
.\gradlew.bat :app:assembleDebug

Готовый debug APK:

C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\android\app\build\outputs\apk\debug\app-debug.apk

Имя app-debug.apk — нормальное. Это имя модуля и типа сборки. Название приложения под иконкой берётся из android:label и равняется StudyPulse.

## 4. Установка APK на своё устройство

Подключи телефон через USB.

Включи на телефоне:

Настройки -> О телефоне -> Номер сборки -> несколько нажатий
Настройки -> Для разработчиков -> Отладка по USB

Проверь устройство:

adb devices

Установи APK:

adb install -r "C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\android\app\build\outputs\apk\debug\app-debug.apk"

Если приложение уже установлено и есть конфликт подписи:

adb uninstall com.studypulse.sync
adb install "C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\android\app\build\outputs\apk\debug\app-debug.apk"

## 5. Запуск backend

Backend нужен только для синхронизации, рейтинга, XP и учебных пакетов.

Основные офлайн-функции работают без backend.

Перейди в папку backend:

cd C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\backend

Создай виртуальное окружение, если ещё не создано:

python -m venv venv
venv\Scripts\Activate.ps1

Установи зависимости:

pip install -r requirements.txt

Запусти сервер:

python app.py

Сервер обычно доступен локально:

http://127.0.0.1:5000

Для Android-эмулятора используется:

http://10.0.2.2:5000

Для реального телефона в той же Wi-Fi сети используется IP ноутбука, например:

http://192.168.1.123:5000

## 6. Настройка сервера в приложении

Обычному пользователю технические настройки не нужны.

Для разработчика:

Настройки -> Для разработчиков -> Адрес сервера

Для эмулятора:

http://10.0.2.2:5000

Для реального телефона в той же сети:

http://<IP-ноутбука>:5000

Пример:

http://192.168.1.123:5000

Если backend не нужен, приложение можно показывать полностью офлайн.

## 7. Проверка основного сценария

После установки:

1. Запусти приложение.
2. Пройди онбординг.
3. Укажи имя.
4. Выбери время учёбы.
5. Включи напоминания и автоплан.
6. Добавь хотя бы одно задание.
7. Вернись на экран "Сегодня".
8. Убедись, что план появился автоматически.
9. Открой Настройки.
10. Проверь резервную копию.
11. Проверь виджет на главном экране телефона.

## 8. Проверка напоминаний

Для быстрой проверки создай задание с дедлайном на завтра и учебный слот примерно через 15-20 минут.

Включи:

Настройки -> Напоминания
Настройки -> Типы напоминаний -> Учебные слоты
Настройки -> Типы напоминаний -> Дедлайны
Настройки -> Типы напоминаний -> Утренний дайджест

Приложение планирует напоминания через WorkManager.

Тихие часы подавляют уведомления, если текущее время попадает в интервал.

## 9. Передача APK сокоманднику

Есть три нормальных способа.

### Способ A. Через USB и adb

Это самый надёжный способ.

Сокомандник подключает свой телефон к твоему ноутбуку.

На телефоне сокомандника включены:

- режим разработчика;
- отладка по USB.

Проверь устройство:

adb devices

Установи APK:

adb install -r "C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\android\app\build\outputs\apk\debug\app-debug.apk"

Если на телефоне уже стоит другая версия StudyPulse с другой подписью:

adb uninstall com.studypulse.sync
adb install "C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\android\app\build\outputs\apk\debug\app-debug.apk"

### Способ B. Отправить файл APK

Просто передай файл:

app-debug.apk

Через:

- Telegram;
- WhatsApp;
- email;
- Google Drive;
- Яндекс.Диск;
- флешку;
- локальную сеть.

Сокомандник открывает APK на телефоне и соглашается установить приложение.

Android может спросить разрешение на установку из неизвестных источников. Это нормально для debug APK.

### Способ C. Локальный HTTP-сервер

Если оба устройства в одной Wi-Fi сети.

На ноутбуке перейди в папку с APK:

cd C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\android\app\build\outputs\apk\debug

Узнай IP ноутбука:

ipconfig

Найди строку IPv4-адрес, например:

192.168.1.123

Запусти сервер:

python -m http.server 8000

Сокомандник на телефоне в браузере открывает:

http://192.168.1.123:8000/app-debug.apk

Скачивает файл и устанавливает.

Если Windows спросит разрешение сети для Python — разреши для частных сетей.

## 10. Если сокомандник хочет синхронизацию с твоим backend

Тогда сокоманднику нужно указать адрес сервера не 10.0.2.2, а IP твоего ноутбука.

Пример:

http://192.168.1.123:5000

Для этого:

1. Твой ноутбуk и телефон сокомандника должны быть в одной Wi-Fi сети.
2. Backend должен слушать не только 127.0.0.1, а 0.0.0.0.
3. В брандмауэре Windows нужно разрешить порт 5000.

Если backend запущен командой:

python app.py

и недоступен с телефона, запусти его так, если в app.py поддерживается host:

python app.py --host 0.0.0.0

или измените запуск Flask на:

app.run(host="0.0.0.0", port=5000, debug=True)

Если такой возможности нет, показывай приложение офлайн.

## 11. Частые проблемы

### Приложение не устанавливается

Причины:

- на телефоне уже установлена версия с другой подписью;
- отключена установка из неизвестных источников;
- APK повреждён при передаче.

Решение:

adb uninstall com.studypulse.sync
adb install app-debug.apk

или переустанови файл.

### CLEARTEXT communication not permitted

Это значит, что приложение пытается обращаться к http-серверу, а Android блокирует небезопасный трафик.

В проекте уже добавлен network_security_config.xml для локальных адресов:

10.0.2.2
localhost
127.0.0.1

Если используешь другой IP ноутбука, добавь его в:

android/app/src/main/res/xml/network_security_config.xml

Пример:

<domain includeSubdomains="false">192.168.1.123</domain>

### Приложение крашится при запуске

Собери заново:

.\gradlew.bat :app:clean
.\gradlew.bat :app:assembleDebug

Проверь логи:

adb logcat | Select-String studypulse

### Виджет не обновляется мгновенно

Виджет обновляется через WorkManager. После изменения плана нужно немного подождать или переоткрыть приложение.

### Напоминания не пришли

Проверь:

- разрешены ли уведомления Android;
- включены ли напоминания в настройках приложения;
- не активны ли тихие часы;
- есть ли запланированный слот или дедлайн;
- не прошло ли время срабатывания до планирования.

## 12. Критерий готовности к демонстрации

Демонстрация готова, если:

- app-debug.apk собирается;
- APK устанавливается на реальный телефон;
- онбординг проходит без краша;
- главный экран открывается;
- задание добавляется;
- автоплан строится автоматически;
- настройки показывают человеческий UI;
- backup создаётся;
- виджет отображается;
- документация README.md и INSTRUCTION.md актуальны.
