# StudyPulse

**StudyPulse** — offline-first учебный ассистент для Android с Flask REST API.

Продукт помогает студенту жить в одном учебном контуре: расписание, задания, материалы, повторение, напоминания, план на день, прогресс, XP, streak и рейтинг. Основное приложение работает локально и без сервера; сервер нужен для учебных пакетов, синхронизации событий и геймификации.

> Текущее состояние: **Фаза 4 завершена**. Продукт приведён в рабочее демо-состояние, основные UX-проблемы исправлены, debug APK готов к передаче сокоманднику.

---

## 1. Ключевая идея

Обычные планировщики хранят задачи. StudyPulse связывает учебный цикл целиком:

```text
расписание -> задания -> план на день -> фокус -> материалы -> повторение -> прогресс -> рейтинг
```

Приложение должно быть не админ-панелью, а ассистентом:

- само предлагать, что делать сегодня;
- напоминать о занятиях и дедлайнах;
- помогать повторять материалы;
- объяснять, где ответ найден, а где нет;
- сохранять прогресс офлайн и синхронизировать его позже.

## 2. Что уже работает

### Android-клиент

- Jetpack Compose / Material 3.
- Offline-first хранение в Room.
- Локальные настройки и профиль студента в DataStore.
- Онбординг при первом запуске.
- Автоплан учебных слотов.
- Экран «Сегодня».
- Расписание:
  - добавление занятия;
  - редактирование локальных занятий;
  - отмена занятия;
  - удаление шаблона;
  - сортировка по дате и времени начала;
  - импорт расписания из текста с предпросмотром и подтверждением.
- Задания и дедлайны.
- Материалы:
  - ручное добавление текстового материала;
  - редактирование локальных материалов;
  - удаление;
  - видимый выбор предмета;
  - прокручиваемая форма;
  - базовая accessibility-семантика.
- Q&A по материалу:
  - честный демо-поиск по ключевым словам;
  - автоматическая чанковка материала при открытии Q&A;
  - регистронезависимый поиск по нескольким ключевым словам;
  - цитаты-источники;
  - понятные состояния: загрузка, ошибка, ответ не найден.
- Интервальное повторение карточек.
- Локализованные компактные кнопки оценки:
  - Снова;
  - Трудно;
  - Хорошо;
  - Легко.
- Локальные уведомления через WorkManager:
  - учебные слоты;
  - дедлайны;
  - утренний дайджест.
- Тихие часы.
- Glance-виджет.
- Статистика:
  - XP;
  - уровень;
  - streak;
  - недельный рейтинг;
  - рейтинг за всё время;
  - автоматическое обновление обоих периодов при открытии и resume экрана.
- Резервные копии на устройстве.
- Технические настройки спрятаны в «Для разработчиков».

### Backend

- Flask REST API.
- Регистрация устройства.
- Учебные пакеты.
- Синхронизация событий.
- Начисление XP.
- Уровень и streak.
- Недельный и общий рейтинг.

## 3. Что сознательно является демо или ограничением

Это важно честно говорить в презентации.

```text
Q&A — не настоящий RAG.
Это keyword-search по локальным материалам и чанкам.

OCR — не настоящий OCR.
Экран «Сканировать конспект» показывает UX будущего сценария, но не распознаёт текст.

Push-уведомления — не серверные.
Есть локальные Android-уведомления через WorkManager.

Аккаунтов нет.
Продукт offline-first: локальный профиль + backup.

Мультидевайс-синхронизации нет.
Есть локальная синхронизация с сервером для рейтинга и пакетов.
```

## 4. Архитектура

```text
Android app
│
├── Jetpack Compose UI
├── ViewModels
├── Domain coordinators
│   ├── AutoPlannerCoordinator
│   └── ProductFlowPolicy
├── Data layer
│   ├── Room local database
│   ├── DataStore settings/profile
│   ├── Retrofit API client
│   ├── BackupManager
│   └── Repositories
├── Workers
│   ├── SyncWorker
│   ├── SlotReminderWorker
│   ├── DeadlineReminderWorker
│   ├── MorningDigestWorker
│   └── WidgetUpdateWorker
└── Glance widget

Flask backend
│
├── /health
├── device registration
├── learning packages
├── package bundle download
├── event sync
├── XP / level / streak
└── leaderboard / stats
```

### Принципы

1. **Offline-first.** Базовый учебный сценарий работает без сервера.
2. **Local-first.** Пользователь может создавать предметы, задания, расписание и материалы локально.
3. **Autopilot.** Приложение само предлагает план, напоминает и синхронизирует прогресс.
4. **Honest AI.** Q&A не выдаётся за полноценный LLM/RAG, если им не является.
5. **Progressive disclosure.** Технические настройки скрыты от обычного пользователя.

## 7. Быстрый старт

### 7.1 Android

Открыть папку:

```text
android/
```

в Android Studio.

Собрать debug APK:

```powershell
Set-Location -LiteralPath 'C:\Users\lelec\AndroidStudioProjects\StudyPulse\StudyPulse\android'
.\gradlew.bat :app:assembleDebug
```

APK будет здесь:

```text

```

### 7.2 Backend

Перейти:

```text
backend/
```

Установить зависимости:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Запустить:

```powershell
python app.py
```

Для доступа с телефона Flask должен слушать:

```python
app.run(host="0.0.0.0", port=5000, debug=True)
```

## 8. Подключение телефона к локальному серверу

1. Телефон и ноутбук в одной Wi-Fi сети.
2. Узнать IP ноутбука:

```powershell
ipconfig
```

3. Найти IPv4, например:

```text
192.168.1.69
```

4. В приложении открыть:

```text
Настройки -> Для разработчиков -> Адрес сервера
```

5. Указать:

```text
http://192.168.1.69:5000
```

6. Если таймаут:
   - открыть порт 5000 в брандмауэре Windows;
   - проверить, что телефон в той же сети;
   - проверить изоляцию клиентов на роутере;
   - или использовать USB и:

```powershell
adb reverse tcp:5000 tcp:5000
```

с адресом:

```text
http://localhost:5000
```

## 9. Основной пользовательский сценарий

```text
1. Первый запуск -> онбординг.
2. Указать имя, время учёбы, дневную нагрузку.
3. Включить уведомления и автоплан.
4. Добавить задание или импортировать расписание.
5. Приложение строит план на день.
6. Пользователь учится по слотам.
7. Открывает материалы и задаёт вопросы.
8. Повторяет карточки.
9. Видит XP, уровень, streak и рейтинг.
10. Создаёт резервную копию.
```

## 10. Демо-сценарий на 3–5 минут

1. Показать установку APK и онбординг.

3. Показать автоплан и экран «Сегодня».

5. Добавить текстовый материал.
6. Открыть Q&A и задать вопрос словом из материала.
7. Показать повторение карточек.
8. Показать статистику и рейтинг.
9. Показать настройки, тихие часы и backup.
10. Показать виджет.
