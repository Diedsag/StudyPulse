# StudyPulse

StudyPulse — offline-first учебный продукт для Android с Flask REST API.

Студент работает с локальными данными, планирует учёбу, повторяет материалы, получает напоминания и синхронизирует прогресс с сервером. Сервер начисляет XP, обновляет уровень, streak и недельный рейтинг.

## Основной сценарий

1. Пользователь устанавливает приложение.
2. Проходит короткий онбординг.
3. Указывает имя, удобное время учёбы и настройки напоминаний.
4. Добавляет задания или получает учебные данные.
5. Приложение автоматически строит план на день.
6. Пользователь видит экран "Сегодня".
7. Приложение напоминает о занятиях и дедлайнах.
8. Прогресс синхронизируется с сервером автоматически.
9. Пользователь видит статистику, XP, уровень и streak.

## Текущий статус

Фаза 2 завершена как рабочий учебный MVP.

Фаза 3 выполнена как продуктовая стабилизация: меньше ручного администрирования, больше автоматизации, понятный пользовательский язык, фоновая синхронизация, точные напоминания, виджет и подготовка APK.

## Реализовано

### Android

- Offline-first хранение данных в Room.
- Локальные предметы, расписание, задания, материалы.
- Экран "Сегодня".
- Учебные слоты и планирование.
- Автоматическое построение плана при включённом автоплане.
- Перепланирование и отметка пропущенных слотов.
- Риски дедлайнов.
- Material 3 дизайн-система.
- Онбординг и локальный профиль студента.
- Человеческие статусы вместо технических PROPOSED / PLANNED / MISSED.
- DataStore для настроек и профиля.
- Retrofit / OkHttp / kotlinx.serialization.
- WorkManager для фоновой синхронизации.
- Локальные напоминания о слотах, дедлайнах и утренний дайджест.
- Тихие часы.
- Glance-виджет с ближайшим слотом, карточками и срочными заданиями.
- Локальный backup и восстановление.
- Mock OCR / импорт расписания из текста.
- Q&A по материалам с цитатами.
- Карточки и повторение.
- Базовые unit-тесты.

### Backend

- Flask REST API.
- Регистрация устройства.
- Учебные пакеты.
- Синхронизация событий.
- XP, уровень, streak, рейтинг.

## Не реализовано в текущем продуктовом скоупе

- Настоящий OCR рукописи.
- Настоящий ASR аудиолекций.
- Настоящий RAG с векторным поиском.
- Облачные LLM в live-режиме.
- Импорт произвольных PDF.
- Google Calendar API.
- Полноценная авторизация.
- Роли преподавателя / студента / администратора.
- Синхронизация между несколькими устройствами.
- Групповой шеринг материалов.
- SQLCipher.
- Маркет-подготовка и релизная инфраструктура.

## Важное уточнение по истории скоупа

В ранних документах Фазы 2 виджет и локальные уведомления могли упоминаться как вне скоупа или demo-элементы.  
В текущей версии они реализованы:

- виджет через Glance;
- локальные напоминания через WorkManager;
- точные напоминания появились в Фазе 3.5;
- полировка виджета появилась в Фазе 3.6.

Актуальный источник истины — этот README и docs/CURRENT_STATE.md.

## Сборка APK

Debug APK собирается командой:

.\gradlew.bat :app:assembleDebug

Готовый файл обычно лежит здесь:

android/app/build/outputs/apk/debug/app-debug.apk

Подробнее смотри в docs/APK_BUILD.md и docs/PHASE3_7_RELEASE_CHECKLIST.md.
