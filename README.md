# StudyPulse

StudyPulse — offline-first учебный продукт для Android с Flask REST API.

Студент получает с сервера учебный пакет, скачивает его в приложение, планирует учебные слоты, повторяет карточки офлайн, а затем синхронизирует прогресс с сервером. Сервер начисляет XP, обновляет уровень, streak и недельный рейтинг.

## Основной сценарий

1. Открыть приложение.
2. Зарегистрировать устройство на сервере.
3. Получить список учебных пакетов.
4. Скачать пакет в локальную базу Room.
5. Посмотреть расписание и задания.
6. Построить план учебных слотов.
7. Учиться офлайн: читать материалы и повторять карточки.
8. Синхронизировать прогресс.
9. Увидеть статистику и рейтинг.

## Структура проекта

    android/   — Android-клиент: Jetpack Compose, Room, DataStore, Retrofit
    backend/   — Flask REST API: SQLite, SQLAlchemy, регистрация устройств, синхронизация, XP, рейтинг
    docs/      — продуктовые и архитектурные документы

## Быстрый старт backend

Из корня проекта:

    Set-Location -LiteralPath backend
    python -m venv venv
    .\venv\Scripts\python.exe -m pip install --upgrade pip
    .\venv\Scripts\python.exe -m pip install -r requirements.txt
    .\venv\Scripts\python.exe seed.py
    .\venv\Scripts\python.exe run.py

После этого API доступен локально:

    http://localhost:5000

Health-check:

    http://localhost:5000/health

## Android

Открой папку:

    android/

в Android Studio.

Для эмулятора используй Server URL:

    http://10.0.2.2:5000/

Важно: указывать именно базовый адрес сервера, без /health на конце.

## Текущий статус разработки

- Блок 0 выполнен: продуктовый скоуп заморожен.
- Блок 1 выполнен: Flask API, регистрация устройства, список учебных пакетов, bundle пакета.
- Блок 2 выполнен: Android Settings skeleton, DataStore, Retrofit, проверка соединения с /health.
- Блок 3 выполнен: Room, список пакетов, скачивание bundle, offline-first хранение учебных данных.
- Блок 4 выполнен: расписание, задания, отмена занятия.
- Блок 5 выполнен: детерминированный планировщик учебных слотов.
- Блок 6 выполнен: материалы, карточки, интервальное повторение, локальная очередь событий.
- Блок 7 выполнен: выполнение учебных слотов, частичное закрытие заданий, события SLOT_COMPLETED / TASK_COMPLETED.
- Блок 8 выполнен: синхронизация батча событий с Flask, идемпотентность через client_event_id, серверный XP, level, weekly XP, streak.
- Блок 9 выполнен: экран статистики, недельный и общий рейтинг, локальный кэш прогресса в Room.
- Блок 10 выполнен: русскоязычный UI, улучшенный дизайн с прокручиваемыми вкладками, фокус-таймер, локальный mock Q&A по материалам, полировка основных сценариев.

## Вне текущего MVP

В текущий MVP не входят:

- настоящий OCR;
- настоящий ASR;
- настоящий RAG;
- векторный поиск;
- импорт произвольных PDF;
- облачные LLM в live-режиме;
- полноценная авторизация;
- роли преподавателя / студента / администратора;
- виджет;
- push-уведомления;
- SQLCipher;
- синхронизация между несколькими устройствами одного пользователя.
