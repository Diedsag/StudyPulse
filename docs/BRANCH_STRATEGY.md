# StudyPulse: стратегия веток

## Основные ветки

### `phase2-freeze`

Замороженная резервная ветка после завершения Фазы 2.

Назначение:

- хранить рабочую версию MVP Фазы 2;
- использоваться как откатная точка;
- не изменяться во время Фазы 3.

Правило:

```text
В phase2-freeze не коммитим новые изменения, если только не делаем экстренный hotfix.
```

### `phase2-complete`

Тег, обозначающий завершение Фазы 2.

Используется для:

- фиксации состояния;
- сравнения;
- возможного возврата к демо Фазы 2.

### `phase3-dev`

Активная рабочая ветка Фазы 3.

Назначение:

- продуктовая стабилизация;
- упрощение UI;
- автоматизация планирования;
- очистка технических настроек;
- улучшение первого запуска;
- подготовка APK.

Правило:

```text
Все работы Фазы 3 ведутся в phase3-dev.
```

### `dev`

Общая development-ветка.

Во время Фазы 3 лучше не использовать `dev` для хаотичных экспериментов, если есть отдельная `phase3-dev`.

### `main`

Стабильная ветка для демонстрации/релиза.

В Фазе 3 обновляем `main` только тогда, когда есть стабильная сборка, которую можно показывать.

---

## Рекомендуемый рабочий процесс

1. Работаем в `phase3-dev`.
2. Делаем небольшие коммиты.
3. Периодически пушим `phase3-dev` в GitHub.
4. Когда блок Фазы 3 готов, проверяем сборку и тесты.
5. После стабильного состояния можно обновить `main`.
6. `phase2-freeze` не трогаем.
