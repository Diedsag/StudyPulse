# StudyPulse: текущее состояние репозитория

Этот документ фиксирует актуальное состояние проекта после Фазы 2 и выполненной Фазы 3.

## 1. Общая архитектура

StudyPulse — offline-first учебное приложение.

Основной источник истины для пользователя — локальная база Room и локальные настройки в DataStore. Flask backend используется для регистрации устройства, выдачи учебных пакетов, синхронизации прогресса и геймификации.

Стек:

- Android: Kotlin, Jetpack Compose, Material 3, Room, DataStore, Retrofit, OkHttp, WorkManager, Glance.
- Backend: Python, Flask, REST API.
- Локальные данные: subjects, schedule, tasks, materials, cards, study slots, pending events, profile, settings.

## 6. Известные продуктовые ограничения

Сейчас проект не является полноценным релизом для Play Market.

Не реализовано:

- настоящая авторизация;
- мультидевайс;
- облачный backup;
- настоящий OCR/ASR;
- настоящий RAG;
- PDF-индексация;
- SQLCipher;
- crash reporting;
- CI/CD;
- store assets.

Это сознательно отложено, потому что текущая цель Фазы 3 была сделать существующий продукт удобнее и автоматичнее.
