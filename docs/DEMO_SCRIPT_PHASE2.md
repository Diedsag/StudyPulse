# StudyPulse Phase 2 Demo Script

## Назначение документа

Это сценарий демонстрации продукта для защиты или показа.

Главная идея демо:

    StudyPulse помогает студенту ответить на два вопроса:
    1. Что именно мне делать сегодня?
    2. Где взять материал, чтобы это сделать?

## Подготовка

Перед демо нужно:

1. Запустить backend.
2. Убедиться, что приложение подключено к серверу.
3. Очистить или подготовить демо-данные.
4. Скачать один учебный пакет для сравнения.
5. Подготовить ручные данные:
   - предмет Физика;
   - занятие Лекция 5;
   - задание Лабораторная №5;
   - материал с саммари и карточками.

## Сценарий на 5 минут

### Шаг 1. Открыть Сегодня

Показать главный экран:

    Сегодня
    Ближайший слот
    Срочные задания
    Карточки к повторению

Комментарий:

    Пользователь сразу видит, что делать дальше.

### Шаг 2. Создать предмет вручную

Перейти в Предметы:

    Добавить предмет Физика
    Выбрать цвет
    Указать преподавателя

Комментарий:

    Приложение не зависит только от серверных пакетов. Студент может вести свои предметы.

### Шаг 3. Добавить занятие вручную

Перейти в Расписание:

    Добавить занятие
    Физика
    Лекция
    Понедельник
    10:00-11:30
    Аудитория 204

Комментарий:

    Расписание становится личным. Его можно менять, когда преподаватель заболел или пару перенесли.

### Шаг 4. Добавить задание

Перейти в Задания:

    Лабораторная №5
    Физика
    Дедлайн завтра
    Трудоёмкость 90 минут
    Приоритет высокий

Комментарий:

    Дедлайн превращается не просто в напоминание, а в объект планирования.

### Шаг 5. Сгенерировать план

Перейти в План:

    Сгенерировать план
    Показать предложенные слоты

Комментарий:

    Планировщик ищет свободные окна с учётом расписания и отменённых занятий.

### Шаг 6. Отменить занятие

Перейти в Расписание:

    Отменить занятие Физика, среда, 14:00

Комментарий:

    Отмена занятия освобождает окно. Это ключевой сценарий реальной студенческой жизни.

### Шаг 7. Перепланировать

Вернуться в План:

    Перепланировать
    Показать новые слоты

Комментарий:

    Приложение не просто строит план один раз. Оно реагирует на изменения.

### Шаг 8. Показать риск дедлайна

Если времени не хватает, показать предупреждение:

    До дедлайна осталось мало времени.
    Запланировано меньше минут, чем требуется.

Комментарий:

    Продукт честно говорит о риске, а не создаёт иллюзию, что всё успевается.

### Шаг 9. Открыть материал из слота

В слоте показать:

    Материал: Лекция 5, термодинамика
    Открыть саммари

Комментарий:

    Связка слот и материал — ключевое отличие от обычного планировщика.

### Шаг 10. Задать вопрос и получить цитату

В материале:

    Спросить: Что такое первое начало термодинамики?

Показать ответ:

    По вашим материалам:
    Цитата из чанка
    Источник: Физика, Лекция 5, стр. 2

Комментарий:

    Это mock RAG без внешнего LLM. Важно не магия ИИ, а честный источник ответа.

### Шаг 11. Повторить карточки

Перейти в Материалы:

    Повторить карточки
    Оценить Again / Hard / Good / Easy

Комментарий:

    Интервальное повторение встроено в учебный процесс, а не живёт отдельным приложением.

### Шаг 12. Синхронизировать прогресс

Перейти в Настройки:

    Синхронизировать

Показать:

    Очередь событий
    Принятые события
    XP
    Уровень
    Streak

Комментарий:

    Все действия создают локальные события. Сервер начисляет XP идемпотентно.

### Шаг 13. Показать статистику и рейтинг

Перейти в Статистика:

    Мой прогресс
    Недельный рейтинг
    Рейтинг за всё время

Комментарий:

    Геймификация не главная цель, но она помогает показать связку действий и прогресса.

## Ключевые акценты для защиты

Нужно подчеркнуть:

1. Offline-first.
2. Local-first модель данных.
3. Объяснимый планировщик.
4. Честный Q&A с цитатами.
5. Идемпотентная синхронизация.
6. Отсутствие зависимости от облачного LLM в демо.
7. Путь к настоящему RAG без преждевременной сложности.

## Что говорить про AI

Правильная формулировка:

    Сейчас в приложении есть mock RAG и локальный Q&A по сохранённым материалам.
    Это сделано сознательно: для учебного MVP важнее предсказуемость, офлайн-режим и объяснимость.
    Архитектура уже подготовлена к настоящему RAG: материалы разбиваются на чанки, ответы могут содержать цитаты, источник хранится локально.

Не нужно обещать:

    живой LLM;
    настоящий OCR;
    векторный поиск;
    облачную обработку прямо сейчас.

## Минимальный сценарий на 2 минуты

Если времени мало:

1. Открыть Сегодня.
2. Показать ближайшее задание и слот.
3. Отменить занятие.
4. Перепланировать.
5. Открыть материал.
6. Задать вопрос и показать цитату.
7. Синхронизировать и показать XP.
