# StudyPulse — известные ограничения

Этот файл нужен, чтобы на защите/демо не выглядеть так, будто ограничения случайны. Они осознаны.

---

## 1. Q&A не является настоящим RAG

Текущая реализация:

```text
keyword search по чанкам материала;
регистронезависимый поиск по нескольким словам;
цитаты из найденных фрагментов.
```

Это не:

```text
векторный поиск;
семантический retrieval;
LLM-генерация ответа;
гибридный reranking.
```

Формулировка для презентации:

> Мы сознательно не выдаём keyword search за RAG. Это продуктовый UX будущего AI-ассистента и подготовленная архитектура материалов и чанков.

---

## 2. OCR не распознаёт текст

Экран «Сканировать конспект» — placeholder.

Он показывает UX будущего сценария:

```text
выбор фото;
название;
предмет;
понимание, что OCR ещё не подключён.
```

Настоящий OCR требует:

```text
ML Kit или облачный API;
обработку качества фото;
печатный текст;
рукописный текст;
post-processing.
```

---

## 3. Push-уведомления не серверные

Есть локальные Android-уведомления через WorkManager:

```text
учебные слоты;
дедлайны;
утренний дайджест.
```

Нет серверных push через Firebase/FCM.

Формулировка:

> Реализованы локальные системные напоминания. Серверные push оставлены на post-MVP.

---

## 4. Нет аккаунтов

Продукт offline-first. Есть:

```text
локальный профиль;
device UID;
локальный backup.
```

Нет:

```text
email/password;
OAuth;
облачного профиля;
мультидевайс.
```

---

## 5. Рейтинг требует сервера

Локальные учебные функции работают офлайн. Сервер нужен для:

```text
XP;
уровня;
streak;
недельного рейтинга;
рейтинга за всё время.
```

Если backend недоступен, статистика может показать ошибку сети. Это ожидаемо.

---

## 6. Импорт расписания из текста — демо-парсер

Он умеет разбирать простой формат:

```text
Понедельник
10:00-11:30 Физика, лекция, ауд 204, Иванов А.П.
```

Но не является универсальным парсером любых расписаний.

---

## 7. Релизные технические долги

```text
нет CI/CD;
нет crash reporting;
нет instrumented/UI тестов;
нет подписанного release AAB;
нет Privacy Policy;
нет production backend конфигурации;
нет нормальной Room migration strategy.
```

Это нормально для демо Фазы 4, но обязательно перед магазином.
