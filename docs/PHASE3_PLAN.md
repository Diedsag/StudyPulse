# StudyPulse: Фаза 3 — продуктовая стабилизация

## Цель Фазы 3

Сделать приложение удобнее для реального пользователя.

Главный принцип:

меньше ручного администрирования, больше автоматизации, меньше технических терминов, больше понятного пользовательского языка.

## Реалистичный объём

Учитывая ограниченное время, Фаза 3 была сокращена до практически полезных изменений.
