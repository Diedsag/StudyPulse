## 2. Что проверено вручную

```text
1. Онбординг проходит без краша.
2. Главный экран открывается.
3. Расписание:
   - добавить занятие;
   - все дни недели видны;
   - форма скроллится;
   - форму можно закрыть;
   - кнопки Отменить/Редактировать/Удалить не вылезают за экран;
   - занятия отсортированы по дате и времени.
4. Импорт расписания:
   - вставил текст;
   - распознал;
   - увидел предпросмотр;
   - прокрутил вниз;
   - нажал Импортировать выбранные;
   - занятия добавились.
5. Материалы:
   - кнопка Добавить открывает форму;
   - форму можно закрыть;
   - выбранный предмет visibly подсвечен;
   - есть подпись Выбранный предмет;
   - сохранённый материал виден в списке с текстом;
   - пустое название не сохраняется.
6. Q&A:
   - добавлен локальный материал;
   - открыт вопрос по материалу;
   - запрос словом из текста даёт ответ с цитатой.
7. Повторение карточек:
   - кнопки Снова/Трудно/Хорошо/Легко компактные и не рвутся по буквам.
8. Статистика:
   - открывается и загружает рейтинг автоматически;
   - обновляются оба периода: неделя и всё время.
9. Настройки:
   - backup создаётся без краша;
   - повторный вход в настройки не крашится;
   - тихие часы отображаются корректно;
   - технические настройки спрятаны в Для разработчиков.
10. Виджет:
   - добавляется;
   - показывает дату/ближайший слот/срочные задания;
   - клик открывает приложение.
```
