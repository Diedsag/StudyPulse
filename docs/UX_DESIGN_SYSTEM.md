# StudyPulse UX Design System

## Назначение документа

Этот документ описывает дизайн-систему StudyPulse для Фазы 2.

Цель:

- сделать интерфейс понятным;
- убрать визуальный шум;
- привести приложение к Material 3;
- обеспечить офлайн-удобство;
- подготовить UI к экрану Сегодня, ручному вводу, уведомлениям и виджету.

## Информационная архитектура

Текущая навигация после Блока 10:

    Пакеты
    Расписание
    Задания
    План
    Материалы
    Статистика
    Настройки

Для ежедневного продукта это слишком широко.

Целевая структура Фазы 2:

    Сегодня
    Учёба
    Материалы
    Профиль

Внутри Учёба:

    План
    Расписание
    Задания

Внутри Материалы:

    Список материалов
    Карточки
    Q&A

Внутри Профиль:

    Статистика
    Рейтинг
    Учебные пакеты
    Синхронизация
    Настройки
    Экспорт и импорт
    О приложении

Пакеты не обязательно держать как главную вкладку. Это источник контента, а не ежедневный экран.

## Главный экран Сегодня

Структура:

    Приветствие и дата
    Streak, XP, прогресс дня

    Ближайший слот
    Кнопка Запустить фокус
    Кнопка Открыть материал

    Срочные задания
    Карточки к повторению

    Быстрые действия
    Добавить задание
    Добавить занятие
    Добавить материал

Принцип:

    Пользователь за 3 секунды должен понять, что делать дальше.

## Цветовая система

Используем роли Material 3, а не произвольные цвета.

| Роль | Использование |
|---|---|
| primary | основные действия: Принять план, Запустить фокус |
| onPrimary | текст на основной кнопке |
| primaryContainer | мягкие акцентные плашки |
| secondary | второстепенные действия, метаинформация |
| tertiary | предупреждения, XP, streak, рейтинг |
| error | просрочки, отменённые занятия, ошибки сети |
| surface | фон экранов |
| surfaceVariant | карточки, поля, разделители |
| outline | границы полей и карточек |

## Светлая палитра

Ориентировочные токены:

    primary: синий учебный акцент
    secondary: teal для спокойных вспомогательных действий
    tertiary: amber для XP, streak, рисков
    error: красный для просрочек и ошибок
    background: очень светлый холодный серый
    surface: белый
    surfaceVariant: светло-серый

## Тёмная палитра

Ориентировочные токены:

    primary: светлый синий
    secondary: светлый teal
    tertiary: мягкий amber
    error: светлый красный
    background: почти чёрный холодный серый
    surface: тёмно-серый
    surfaceVariant: чуть светлее surface

## Dynamic color

Для Android 12+ можно использовать dynamic color, но для учебного демо лучше дать переключатель:

    Настройки -> Оформление -> Динамические цвета

Значения:

    Авто
    Включить
    Выключить

Причина:

    На разных телефонах приложение не должно выглядеть по-разному во время защиты.

## Типографика

Для учебного приложения важна читаемость.

Рекомендуемые размеры:

    displaySmall: крупные таймеры и цифры
    headlineSmall: заголовки экранов
    titleLarge: заголовки карточек
    titleMedium: названия слотов, заданий, материалов
    bodyLarge: основной читаемый текст
    bodyMedium: обычный текст
    bodySmall: метаинформация
    labelMedium: чипы, статусы, кнопки
    labelSmall: подписи источников и времени

Правила:

- не использовать слишком мелкие шрифты для учебного текста;
- таймер фокуса должен быть крупным;
- дедлайны и статусы должны читаться сразу;
- длинные названия заданий ограничивать двумя строками.

## Формы и shapes

Рекомендации:

    Card: large или medium radius
    Button: small или medium radius
    TextField: small radius
    Bottom sheet: extraLarge top radius
    Chip: small radius

Не делать чрезмерно круглые карточки, если внутри плотный учебный текст.

## Компоненты

Нужно вынести переиспользуемые компоненты.

### StudyPulseCard

Базовая карточка для:

- слота;
- задания;
- материала;
- статистики;
- empty state.

### SectionHeader

Заголовок секции с возможным действием:

    Срочные задания        Все задания
    Карточки к повторению  Повторить все

### StatusChip

Чипы статусов:

    Просрочено
    Сегодня
    Отменено
    Готово
    Осталось 30 мин
    Доступно офлайн

Тоны:

    Neutral
    Info
    Success
    Warning
    Danger

Важно:

    Статус нельзя передавать только цветом. Всегда нужен текст.

### EmptyState

Пример:

    Пока нет заданий.
    Добавьте первое задание вручную или скачайте учебный пакет.

    Кнопка Создать задание
    Кнопка Открыть пакеты

### ErrorState

Пример:

    Не удалось синхронизировать прогресс.
    Проверьте подключение к серверу и попробуйте снова.

    Кнопка Повторить
    Кнопка Открыть настройки

### LoadingState

Не показывать голый spinner без контекста.

Лучше:

    Загружаем карточки...
    Строим план...
    Синхронизируем прогресс...

### SubjectDot

Маленький цветной индикатор предмета.

Используется в:

- расписании;
- заданиях;
- материалах;
- слотах;
- виджете.

### DeadlineBadge

Показывает:

    Сегодня
    Завтра
    3 дня
    Просрочено

### SlotTimeRow

Формат:

    18:00-19:30
    Лабораторная по физике

### QuickActionButton

Быстрые действия:

    + Задание
    + Занятие
    + Материал

## Состояния экранов

Для каждого экрана нужны 4 состояния:

    Loading
    Empty
    Error
    Content

Это особенно важно для:

- Сегодня;
- Расписание;
- Задания;
- План;
- Материалы;
- Статистика;
- Синхронизация.

## Feedback и undo

Критичные действия должны давать обратную связь.

Действия:

    Отменить занятие
    Выполнить слот
    Принять план
    Синхронизировать
    Повторить карточку
    Удалить задание

После действия показывать snackbar:

    Занятие отменено.
    [Отменить действие]

    Слот отмечен выполненным.
    [Отменить]

    Задание удалено.
    [Восстановить]

## Формы и валидация

### Задание

Поля:

    Название
    Предмет
    Дедлайн
    Трудоёмкость
    Приоритет
    Описание

Валидация:

    Название обязательно
    Дедлайн не может быть в прошлом при создании
    Трудоёмкость больше 0
    Приоритет от 1 до 3

### Занятие

Поля:

    Предмет
    Тип
    День недели
    Начало
    Конец
    Аудитория
    Преподаватель
    Чётность

Валидация:

    Конец позже начала
    Время в диапазоне 00:00-23:59
    Предмет обязателен
    Проверка пересечений с другими занятиями в этот день

Если пересечение:

    Это занятие пересекается с История, 10:00-11:30.
    Продолжить всё равно?

## Доступность

Минимальный набор:

    Touch target не меньше 48dp
    Контраст текста не меньше 4.5:1
    Поддержка large font
    Semantic labels для иконок
    Не полагаться только на цвет

Особенно важно для:

- кнопок фокуса;
- чипов статусов;
- цветов предметов;
- ошибок форм;
- уведомлений.

## Локализация

Сейчас много русских строк захардкожено в Compose.

Для Фазы 2 нужно вынести строки в resources.

Пример:

    tab_today
    tab_study
    tab_materials
    tab_profile

    next_slot
    start_focus
    open_material

    tasks_due_soon
    cards_ready

    empty_tasks_title
    empty_tasks_message

Для множественного числа использовать plurals:

    одна карточка
    две карточки
    пять карточек

## Motion

Анимации должны быть быстрыми и не мешать чтению.

Рекомендации:

    transition: 150-250 ms
    snackbar: стандартный Material
    tab switch: без тяжёлых анимаций
    focus timer: минимум движения, крупный текст
    pull-to-refresh: стандартный Material

## Виджет

Виджет должен быть читаемым с главного экрана.

Минимум:

    Ближайший слот
    Ближайший дедлайн
    Кнопка Открыть план

Опционально:

    Карточки к повторению
    Streak

Не перегружать виджет статистикой и рейтингом.

## Итоговые UX-приоритеты Фазы 2

1. Экран Сегодня.
2. Ручное добавление предметов, заданий, расписания и материалов.
3. Понятные empty и error states.
4. Undo для опасных действий.
5. Статусы слотов и заданий через текст, а не только цвет.
6. Крупный и читаемый фокус-таймер.
7. Релевантные материалы внутри слота.
8. Цитаты в Q&A.
9. Виджет и уведомления.
10. Локализация строк и базовая доступность.
