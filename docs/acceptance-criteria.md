# StudyPulse Acceptance Criteria

Это критерии, по которым продукт считается готовым как MVP.  
Только рабочий продукт. Без презентации и видео.

## Backend

- [ ] Flask запускается без ошибок.
- [ ] GET /health возвращает 200 и JSON.
- [ ] SQLite база создаётся автоматически.
- [ ] Seed добавляет минимум 2 учебных пакета.
- [ ] Каждый пакет имеет:
  - расписание;
  - задания;
  - материал;
  - карточки.
- [ ] POST /api/devices/register создаёт устройство.
- [ ] Повторная регистрация того же device_uid не создаёт дубль.
- [ ] GET /api/packages возвращает пакеты для устройства.
- [ ] GET /api/packages/{id}/bundle возвращает полный пакет.
- [ ] POST /api/sync/batch принимает события.
- [ ] Дубли client_event_id не начисляют XP повторно.
- [ ] Невалидный rating отклоняется.
- [ ] Batch больше 100 событий отклоняется.
- [ ] occurred_at слишком в будущем отклоняется или ограничивается.
- [ ] GET /api/me/stats возвращает корректную статистику.
- [ ] GET /api/leaderboard возвращает топ и своё место.
- [ ] XP считается на сервере.
- [ ] Level обновляется по таблице уровней.
- [ ] Streak обновляется корректно.
- [ ] Weekly leaderboard сортируется по weekly_xp.

## Android: запуск и настройки

- [ ] Приложение запускается без crash.
- [ ] device_uid генерируется один раз.
- [ ] device_uid сохраняется в DataStore.
- [ ] server URL можно изменить в настройках.
- [ ] nickname можно задать или использовать дефолтный.
- [ ] Кнопка «Проверить соединение» показывает Connected / Offline / Error.
- [ ] При неверном URL приложение не падает.
- [ ] При пустом URL приложение показывает ошибку.

## Android: пакеты

- [ ] Приложение получает список пакетов с сервера.
- [ ] Пакеты сохраняются в Room.
- [ ] При отсутствии сети показывается кэш.
- [ ] Пользователь может скачать пакет.
- [ ] После скачивания пакет имеет статус «Доступен офлайн».
- [ ] Bundle сохраняется в Room транзакцией.
- [ ] Если bundle частично пришёл криво, транзакция откатывается и приложение не падает.

## Android: расписание и задания

- [ ] Пользователь видит занятия скачанного пакета.
- [ ] Пользователь видит задания скачанного пакета.
- [ ] Занятие можно отменить.
- [ ] Отменённое занятие не мешает планировщику.
- [ ] Задание имеет дедлайн, трудоёмкость, приоритет и статус.

## Android: планировщик

- [ ] Кнопка «Спланировать» работает локально.
- [ ] Планировщик учитывает занятые интервалы.
- [ ] Планировщик учитывает отменённые занятия.
- [ ] Планировщик создаёт слоты не меньше 30 минут.
- [ ] Планировщик не превышает дневной лимит 180 минут.
- [ ] Планировщик не ставит слоты в прошедшее время.
- [ ] Пользователь видит предпросмотр плана.
- [ ] Пользователь может принять план.
- [ ] После принятия слоты имеют статус PLANNED.
- [ ] Создаётся событие PLAN_ACCEPTED.

## Android: учебный слот

- [ ] Слот можно открыть.
- [ ] В слоте видна задача.
- [ ] Если есть материал, он открывается.
- [ ] Если есть карточки, можно запустить повторение.
- [ ] Слот можно отметить выполненным.
- [ ] Создаётся событие SLOT_COMPLETED.
- [ ] Повторное выполнение не должно ломать приложение.

## Android: интервальное повторение

- [ ] Приложение берёт только cards, где dueAt <= now.
- [ ] Показывается front.
- [ ] Показывается back по кнопке.
- [ ] Доступны оценки Again / Hard / Good / Easy.
- [ ] После Again карточка возвращается в ближайшей сессии.
- [ ] После Good/Easy interval увеличивается.
- [ ] Сохраняется ReviewLog.
- [ ] Создаётся PendingEvent CARD_REVIEWED.
- [ ] Если due cards нет, показывается empty state.

## Android: синхронизация

- [ ] Локальные события хранятся со synced=false.
- [ ] Пользователь видит pending events count.
- [ ] Кнопка «Синхронизировать» отправляет батч.
- [ ] При успехе события помечаются synced=true.
- [ ] При ошибке события остаются synced=false.
- [ ] Повторная синхронизация не создаёт дублей на сервере.
- [ ] После sync обновляется last_sync_at.
- [ ] После sync обновляется статистика.
- [ ] После sync обновляется рейтинг.

## Android: статистика и рейтинг

- [ ] Пользователь видит total XP.
- [ ] Пользователь видит weekly XP.
- [ ] Пользователь видит level.
- [ ] Пользователь видит streak.
- [ ] Пользователь видит reviews today.
- [ ] Пользователь видит completed slots.
- [ ] Пользователь видит pending events count.
- [ ] Пользователь видит своё место в рейтинге.
- [ ] Рейтинг кэшируется локально.
- [ ] При отсутствии сети рейтинг показывается из кэша.

## Offline-first

- [ ] Без интернета можно открыть скачанный пакет.
- [ ] Без интернета можно построить план.
- [ ] Без интернета можно повторить карточки.
- [ ] Без интернета можно отметить слот выполненным.
- [ ] Все действия создают локальные события.
- [ ] Приложение не пытается каждый чих ходить в сеть.

## Устойчивость

- [ ] Нет crash при пустом списке пакетов.
- [ ] Нет crash при пустом bundle.
- [ ] Нет crash при отсутствии карточек.
- [ ] Нет crash при отсутствии заданий.
- [ ] Нет crash при отсутствии материалов.
- [ ] Нет crash при ошибке сети.
- [ ] Нет crash при невалидном JSON.
- [ ] Нет ANR при сетевых запросах.
- [ ] Нет ANR при планировании.
- [ ] Нет ANR при синхронизации большого батча.

## Минимальный продуктовый сценарий для проверки

1. Запустить Flask.
2. Запустить Android emulator.
3. Убедиться, что emulator открывает http://10.0.2.2:5000/health.
4. Открыть StudyPulse.
5. Проверить соединение.
6. Скачать пакет.
7. Построить план.
8. Включить airplane mode.
9. Пройти 3–5 карточек.
10. Отметить слот выполненным.
11. Выключить airplane mode.
12. Нажать Sync.
13. Убедиться, что pending events стало 0.
14. Убедиться, что XP/level/streak обновились.
15. Открыть leaderboard и увидеть своё место.
